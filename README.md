# Comparador de renda fixa

Simulador público: compara até 3 aplicações de renda fixa no mesmo valor, data e prazo, já descontados IR, IOF e custos.

- Nada do que você digita é gravado no navegador nem enviado a ninguém; os cenários somem ao fechar a página.
- Só os dados de mercado vêm do Banco Central (SGS e Focus).
- Análise, não recomendação de investimento.

Este repositório tem só o site gerado; o código-fonte e os testes ficam em repositório privado.
